# На грани

Русскоязычная интерактивная новелла о холодной войне 1945–1991 годов: 15 эпизодов, две стороны, 90 вариантов решений.

## Запуск

Откройте **index.html** двойным щелчком в современном Chrome, Edge или Firefox. Установка и интернет для игры не нужны. Интернет понадобится при переходе на исторические источники.

Если браузер ограничивает сохранение при открытии локальных файлов, запустите в папке проекта:

```powershell
node server.cjs
```

Затем откройте **http://127.0.0.1:4173**. Остановка сервера: Ctrl+C. Если порт занят или запрещён, выберите другой: `node server.cjs 4174`. Прогресс хранится отдельно для каждого адреса и браузера: сохранение из локального файла не переносится автоматически на localhost.

## Управление

- Выберите США или СССР, прочитайте ситуацию и примите одно из трёх решений.
- После решения показаны условные последствия, историческая справка и источники.
- Клавиши 1–3 выбирают решение; Tab и Enter управляют кнопками; Esc закрывает окно.
- Прогресс сохраняется автоматически. На главном экране есть продолжение.
- «Журнал решений» позволяет скачать прохождение в TXT. Архив и правила доступны сверху.
- При новой кампании игра предлагает подтвердить замену текущего сохранения.

## Файлы

| Файл | Назначение |
| --- | --- |
| `Сценарий.txt` | Полный отдельный сценарий: обе стороны, решения, эффекты, источники |
| `Описание реализованного.txt` | Выполненная работа, ограничения и шаблон обратной связи |
| `data.js` | Редактируемые данные сценария |
| `engine.js` | Механика, переходы, финалы, проверка сохранений |
| `app.js` | Интерфейс, журнал, архив, управление |
| `styles.css`, `assets/` | Адаптивное оформление и векторные иллюстрации |
| `tests/` | Проверки логики и браузерных сценариев |

После редактирования `data.js` обновите текстовый сценарий:

```powershell
node scripts/export-scenario.cjs
```

## Проверка

Механика: Node.js 18+ без зависимостей.

```powershell
node --test tests/engine.test.cjs
```

Браузерная проверка: Python, Playwright и установленный Google Chrome. Эти инструменты нужны только разработчику, для игры они не требуются.

```powershell
python -m pip install -r tests/requirements.txt
python tests/browser_smoke.py
```

Скриншоты и выгруженные журналы тестов сохраняются в `test-artifacts/`.

## Историческая рамка

Даты и справки опираются на архивные и исследовательские материалы; ссылки находятся в каждом эпизоде и в сценарии. Вымышленных цитат нет. Применённые источники перечислены с указанием типа; личная рецензия историка не проводилась.

Числа, альтернативные последствия и условия финалов — авторская учебная модель. Новый эпизод возвращается к историческим обстоятельствам своей даты, сохраняя игровые показатели. Поэтому игра показывает отдельные развилки с накоплением последствий, а не полностью переписанную историю мира. Карта и символы сторон — стилизованные иллюстрации.
