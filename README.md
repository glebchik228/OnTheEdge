# На грани

Русскоязычная интерактивная новелла о холодной войне 1945–1991 годов. Версия 2.0: 19 глав, две стороны, 114 базовых вариантов решений, 11 условных вариантов сцен и 14 концовок.

## Запуск

Откройте **index.html** двойным щелчком в современном Chrome, Edge или Firefox. Установка и интернет для игры не нужны. Интернет понадобится при переходе на исторические источники.

Если браузер ограничивает сохранение при открытии локальных файлов, запустите в папке проекта:

```powershell
node server.cjs
```

Затем откройте **http://127.0.0.1:4173**. Остановка сервера: Ctrl+C. Если порт занят или запрещён, выберите другой: `node server.cjs 4174`. Прогресс хранится отдельно для каждого адреса и браузера: сохранение из локального файла не переносится автоматически на localhost.

## Управление

- Выберите США или СССР, прочитайте ситуацию и примите одно из трёх решений.
- В каждой главе объясняются происхождение конфликта, интересы участников и значение выбора. «Показать исторические подсказки» помогает пройти исторический маршрут.
- Прошлые договоры и реформы меняют следующие сцены. Внутренняя политика влияет на текущий бюджет, регулярные расходы, экономику и устойчивость.
- Исход большой обычной войны зависит от экономики, армии и союзников обеих сторон. Ядерное применение ведёт к катастрофе.
- После решения показаны условные последствия, историческая справка и источники.
- Клавиши 1–3 выбирают решение; Tab и Enter управляют кнопками; Esc закрывает окно.
- Прогресс сохраняется автоматически. На главном экране есть продолжение.
- «Журнал решений» позволяет скачать прохождение в TXT. Архив и правила доступны сверху.
- При новой кампании игра предлагает подтвердить замену текущего сохранения.

После обновления с версии 1 нужно начать новую кампанию: формат и правила изменились. Старое сохранение остаётся в браузере, версия 2 использует отдельный ключ.

## Файлы

| Файл | Назначение |
| --- | --- |
| `Сценарий.txt` | Полный отдельный сценарий: обе стороны, решения, эффекты, источники |
| `Описание реализованного.txt` | Выполненная работа, ограничения и шаблон обратной связи |
| `data.js` | Исходные исторические главы и источники |
| `campaign-data.js` | Экспозиция, внутренняя политика, исследования, словарь |
| `branches.js` | Условия и тексты альтернативных сцен |
| `engine.js` | Механика, переходы, финалы, проверка сохранений |
| `app.js` | Интерфейс, журнал, архив, управление |
| `styles.css`, `assets/` | Адаптивное оформление и векторные иллюстрации |
| `tests/` | Проверки логики и браузерных сценариев |

После изменения сценария или механики обновите текстовый сценарий:

```powershell
node scripts/export-scenario.cjs
```

## Проверка

Механика: Node.js 18+ без зависимостей.

```powershell
node --test tests/engine.test.cjs
```

Браузерная проверка: Python, Playwright и установленный Google Chrome. Эти инструменты нужны только разработчику, для игры они не требуются.

```powershell
python -m pip install -r tests/requirements.txt
python tests/browser_smoke.py
```

15 тестов механики включают 2 000 воспроизводимых маршрутов, все концовки, сохранения и зависимости решений. Браузерная проверка проходит исторические кампании, изменённый Берлин, советскую победу, военные развилки, экспорт и экраны шириной 320/390 px. Скриншоты и выгруженные журналы сохраняются в `test-artifacts/`.

## Историческая рамка

Даты и справки опираются на архивные и исследовательские материалы; ссылки находятся в каждом эпизоде и в сценарии. Вымышленных цитат нет. Применённые источники перечислены с указанием типа; личная рецензия историка не проводилась.

Числа, альтернативные последствия и условия финалов — авторская учебная модель. В архиве отдельно объяснено, что следует из работ Марка Харрисона, Владислава Зубока и архивных документов, а что предполагает игра. Победа СССР и исход большой войны не представлены как доказанные прогнозы историков.

Изменённые обстоятельства сохраняются в связанных главах: например, раннее сотрудничество открывает Берлин без блокады, а реформы и новый договор — возможность сохранения Союза. Календарь, исторические руководители и события вне предусмотренных веток остаются опорными точками; полной симуляции мировой истории нет. Карта и символы сторон — стилизованные иллюстрации.
